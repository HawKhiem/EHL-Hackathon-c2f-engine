Important problems remaining
1. Removing parsing disables chunking.
Because case["items"] is always empty, [run.py (line 226)](/Users/crsaw7/HackathonSep/EHL-Hackathon-template-repo/c2f/run.py:226) sends every invoice through one model call. Game 28’s ten items finished in 12.8 seconds, but the 29–39-item cases are now untested and could miss the deadline.
2. We can no longer detect missing items.
If the model silently skips a POS number, the pipeline no longer knows that it was omitted.
3. Category calibration is lost.
Every model result now has _description="", so labour, drying, electronics, and material all use the global calibration rather than their category-specific bias.
